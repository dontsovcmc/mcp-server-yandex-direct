# Исследование ключевых слов

2 действия в домене `research`.

| Команда | Описание | Параметры |
|---------|----------|-----------|
| `keywordsresearch-deduplicate` | Дедуплицировать ключевые слова (убрать дубликаты) | `Keywords` (list[str]) \* |
| `keywordsresearch-has-search-volume` | Проверить наличие поискового спроса для ключевых слов | `Keywords` (list[str]) \* |

\* — обязательный параметр
